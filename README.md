# Coverage Report

Nástroj pro sledování pokrytí u zákazníka. Jeden HTML soubor, všechno běží
v prohlížeči, data z nahraného sešitu nikam neodcházejí.

**Online:** https://uhanm056.github.io/Coverage-report-/

Použití: otevřít odkaz, nahrát aktuální `Coverage.xlsx`, číst nebo exportovat.

Repozitář je veřejný. `Coverage_Report.html` proto nesmí obsahovat žádná
zákaznická data (`let D = null`), workflow to před nasazením kontroluje.
Kontext pro vývoj je v `CLAUDE.md`.
